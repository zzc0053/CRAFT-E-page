# CRAFT-E Project Page

Project page for **CRAFT-E: A Neuro-Symbolic Framework for Embodied Affordance Grounding**.

- Paper: <https://arxiv.org/abs/2512.04231>
- Code: <https://github.com/zzc0053/CRAFT-E>
- Website: <https://zzc0053.github.io/CRAFT-E-page/>

The site is static and can be previewed locally with:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
